    

    Make sure to familiarize yourself with the Exploration Instructions found on the home page.
    🔗
    In this exploration, you will use the python package panchi to explore the relationship between Linear Transformations and the determinant. You will do all the work in a Jupyter Notebook, which will be provided to you and contains all instructions and code you will need to complete the exploration. The final code in the notebook will generate a PDF of your work, which you will submit to Gradescope.
    🔗
    The notebook is hosted in Google Colab, so you will not need to install any software on your computer. You will need a Google account to access the notebook, and you will need to be logged in to Google to run the notebook. If you do not have a Google account, you can create one for free at https://accounts.google.com/signup.
    🔗
    Follow the instructions below to begin the exploration.
    🔗
    1. Open the determinants exploration notebook.
      🔗
      🔗

      🔗
      🔗
    3. Open your copy and enter your name in the top cell by double-clicking it.
      🔗
      🔗
    4. Run the setup cell once, then work through the exploration cell by cell.
      🔗
      🔗

      🔗
